## What an agent needs to know first

- **There is no callable public API today.** TVbeat's own API reference names
  `https://api.tvbeat.com` as the API root. That hostname does not resolve in public DNS
  (NXDOMAIN on the system resolver, 1.1.1.1 and 8.8.8.8, checked 2026-08-12), and the
  reference itself was last modified 2017-05-23.
- **The current product documentation is credential-gated.** `https://docs.tvbeat.com`
  is a SnazzyDocs instance that returns a page titled "Login" for every path. Access
  requires customer credentials; there is no self-serve signup.
- **There is no pricing.** No pricing page, no tiers, no trial. The only commercial
  call-to-action on the site is "Request a demo" (mailto:info@tvbeat.com).
- **There is no OpenAPI, GraphQL, AsyncAPI, MCP server or A2A agent card** anywhere on
  TVbeat's public surface. All of these were probed and all missed.

## The documented API (historical, first-party)

TVbeat published a complete API reference in its own GitHub organization. It describes
an analytics API with three query-shaped operations over a dataset:

- `GET /{dataset}/dimensions` — list the dimensions available for breakdown, filtering
  and target audience.
- `POST /{dataset}/dimensions_search` — search the values of a Set or HugeSet dimension.
  HugeSet dimensions require a `search_string` of at least 2 characters.
- `POST /{dataset}/breakdown` — return TV metrics for a time span, broken down by one
  dimension, constrained by filters.

Authentication is `TVBEAT-HMAC-SHA256`, a per-request HMAC-SHA256 signature scheme
modelled on AWS Signature Version 4: sign a canonical request with a key derived from
`HMAC("TVBEAT" + secret, timestamp)` then `HMAC(key_date, "ae")`, and send it in an
`Authorization` header alongside an `x-tvbeat-date` UNIX timestamp. Access key IDs and
secrets are assigned by TVbeat when an account is opened.

Documented failures: `401` (request not signed correctly), `403` (dataset or dimension
outside the caller's permissions), `429` (rate limit — one concurrent query per
key/secret pair). No error envelope is published and no rate-limit headers are returned.
